# Призма LLM

Электронный аналитический помощник для подготовки справок, докладов и аналитических записок.

## Назначение

- Обработка текстовых материалов и документов пользователя
- Подготовка справок, докладов и аналитических записок по образцам
- Работа с локальными и облачными языковыми моделями
- Проверка источников и разделение фактов, гипотез и неизвестного

## Основа

Проект строится на базе открытого решения [AnythingLLM](https://github.com/Mintplex-Labs/anything-llm), адаптированного под задачи аналитической работы.
